# Тестовые проекты

В этой папке находятся 20 независимых файлов импорта: один JSON — один проект,
в каждом проекте 10 постов. Выберите нужные файлы кнопкой «Проекты → Импорт»;
диалог поддерживает множественный выбор.

Каждый пост содержит обязательный заголовок, не менее пяти случайно
распределённых контентных блоков и структурный блок проекта. В стартовом посте
это карта остальных девяти постов, в остальных — обратная ссылка на карту.

Общий пакет находится уровнем выше: `data/test-projects-bundle.json`. Не
импортируйте его одновременно с отдельными файлами, иначе получите ожидаемые
копии тех же проектов с новыми ID.

Повторная генерация набора:

```bash
node scripts/generate-test-projects.mjs
```
