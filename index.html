Основные настройки Publisher и Telegram Core. Новые разделы будут добавляться в левую панель.

Остановлен

Локальные данные

Проверка защиты хранилища…

Постоянное хранилище защищает IndexedDB от автоматического удаления браузером при нехватке места. Пользователь всё равно может удалить данные сайта вручную.

Резервные копии

Последняя закреплённая копия ещё не проверена

Проверка использует самую новую закреплённую запись по дате отправки. Ручное восстановление перезапускает защищённый вход и импортирует файл до запуска приложения; Bot API token остаётся в CloudStorage.

Бот и long polling

Токен не задан
Бот не проверен

Token проходит проверку при безопасном запуске и постоянно хранится только в зашифрованном виде в Telegram CloudStorage. В IndexedDB и резервные копии token не записывается.

Runtime принимает updates через getUpdates. Активный webhook блокирует long polling.

Владелец

Владелец не привязан

Владелец привязывается сразу по подписанному Telegram initData. Чтобы бот мог отправлять резервные копии и принимать media, один раз нажмите Start в его личном чате.

Что принимать от владельца

Текст, кружочки, стикеры и остальные типы намеренно игнорируются. Принятые media уже выходят из ядра нормализованным событием для будущей Gallery.

Предпросмотр сообщения

Live-preview недоступен без приватного канала
Live-preview ещё не синхронизировался

Live-preview хранится отдельным сообщением в приватном канале. Если сообщение удалено, следующая синхронизация создаст новое. Диалог с ботом используется для загрузки медиа и управления.

Навигация Telegram

ON использует tg://. OFF использует https://t.me/ там, где web-переход возможен. Все модули открывают Telegram только через общий navigation layer.

Индикатор сети

Сохраняется в настройках этого приложения. Индикатор всегда можно развернуть или свернуть кнопкой в верхней панели.

Канал предпросмотра

Слот свободен
Добавить бота администратором

Канал привяжется автоматически, если он приватный, бот добавлен администратором, а участники — только бот и текущий владелец. В остальных случаях используйте ручное подтверждение случайным кодом. После привязки приложение создаст и закрепит отдельное сообщение live-preview; публикации проектов будут размещаться после него.
